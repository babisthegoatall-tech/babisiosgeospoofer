# Babis Hub

Babis Hub is an internal iOS 15+ QA and demo app built with SwiftUI, MapKit, and CoreLocation. It requests When In Use location access to show the device's current position, then lets the user tap a destination and press **Go** to move and center the map on Babis Hub's simulated marker there. Starting a saved route from **Plans** opens the map tab and follows the simulated route position. The real device position remains separately marked. It also supports place search, manual latitude/longitude entry, route playback, favorites, GPX import/export, and locally persisted settings.

## Important limitation and permitted use

Location simulation is app-local: Babis Hub reads the device's real current position (with permission) as a starting reference, but pressing **Go** moves only its own simulated map marker. It cannot teleport the phone's actual GPS position or change another app's location, including Snapchat. It uses no private APIs, jailbreak hooks, or sandbox bypasses. Use only for authorized testing and internal demonstrations. Misuse may violate Apple Enterprise Program terms or Snapchat's Terms of Service and can result in certificate revocation, account restrictions, or bans.

## Xcode project

Open `BabisHub.xcodeproj` with Xcode 15 or later. The deployment target is iOS 15.0. The project is organized as:

```text
BabisHub/
  BabisHubApp.swift
  Models/Place.swift
  Services/LocationSimulationService.swift
  Services/GPXDocument.swift
  ViewModels/HubViewModel.swift
  Views/ContentView.swift
  Views/LibraryView.swift
  Views/MapKitPicker.swift
  Views/SettingsView.swift
  Info.plist
  BabisHub.entitlements
```

Replace `com.example.babishub` with your organization's unique app identifier in `BabisHub.xcodeproj/project.pbxproj` before signing a device build. The Codemagic unsigned build does not require a provisioning profile or Apple Developer Enterprise membership.

The entitlements file is intentionally empty: no special location-simulation entitlement is required. `Info.plist` includes the When In Use location usage explanation. The app's search function uses Apple's MapKit services; a network connection may be required for search and map tiles.

The `LocationSimulating` protocol is injected into the MVVM view model. `CurrentLocationProvider` uses `CLLocationManager` to read the user's authorized real position. `LocationSimulationService` separately moves an app-owned coordinate to the selected destination or along route waypoints; it never publishes or changes a device-wide/system location.

## Build with Codemagic without Enterprise signing

The repository root contains `codemagic.yaml`. Its `ios-unsigned` workflow compiles an iOS device archive with code signing disabled and packages it as `build/BabisHub-unsigned.ipa`, available in the successful build's **Artifacts** section. It requires no Enterprise certificate, provisioning profile, or Codemagic code-signing identity.

1. Add/connect this GitHub repository in Codemagic and select the `main` branch. Codemagic detects the root `codemagic.yaml`.
2. Start the `ios-unsigned` workflow.
3. Download `BabisHub-unsigned.ipa` from **Artifacts** after the build succeeds.

**The IPA is intentionally unsigned and cannot be installed or distributed to iPhones/iPads as-is.** It is a compilation artifact only. Device installation requires signing with a valid Apple certificate and matching provisioning profile. Enterprise membership is not the only option: depending on your distribution goal, a standard Apple Developer Program account can be used for development, Ad Hoc, or App Store/TestFlight signing. Configure Codemagic signing and the matching profile for the chosen Apple distribution method before producing an installable IPA. Never commit certificates, private keys, provisioning profiles, or API keys to the repository.

For simulator testing, build and run the project in Xcode using an iOS Simulator destination; the device IPA generated by this Codemagic workflow is not a simulator app. Violating Apple Enterprise Program terms or Snapchat's Terms of Service can lead to certificate revocation, service/account restrictions, or bans.

## Data and GPX behavior

Favorites, routes, and the default simulation speed are encoded as Codable data in `UserDefaults` on the device. GPX imports accept route, track, and waypoint points; an imported route needs at least two valid points. GPX exports contain the selected saved route.
